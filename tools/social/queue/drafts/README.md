# Чернови за предупреждения

Тук ботът слага **чернови** за оранжев и червен код на НИМХ: картинка (`.jpg`) и текст (`.txt`).
**Нищо от тази папка не се публикува само** – опашката гледа само файловете в `queue/`, не в подпапките.

За всяка чернова ботът отваря **issue** („[чернова] …“), а GitHub ви изпраща имейл.

## Как да решите
Actions → **Social draft** → Run workflow → в „draft“ напишете името от issue-то (без `.jpg`):

- `publish` – премества я в `queue/` и излиза в следващия слот (12:29 или 18:29);
- `publish-now` – излиза веднага;
- `delete` – изтрива я.

Текстът (`<име>.txt`) може да се редактира в GitHub преди одобряване. Най-много 2 нови чернови на ден,
без повторения за едно и също предупреждение (състоянието е в `tools/social/state/warnings.json`).
