# Weather Pulse

Weather forecast, geomagnetic storms, weather maps and a public holiday calendar for any location.
Static site hosted on **GitHub Pages**.

## Live site

👉 [https://weatherpulse.eu/](https://weatherpulse.eu/)

## Pages

### Written by hand

| Folder | Page |
|--------|------|
| `/` | Home |
| `weather/` | Daily (city-style day cards) and hourly forecast for any place |
| `maps/` | Interactive weather maps with favourite locations |
| `holliday_calendar/` | Public holiday calendar by country |
| `magnitni-buri/` | Geomagnetic storms (Kp index) |
| `widget/` | Embeddable Kp widget |

### Generated (do not edit by hand)

| Folder | Generated by |
|--------|--------------|
| `vremeto/`, `vremeto/<city>/`, `praznici/` | `build-pages.js`: hub, 35 city pages and holidays page (texts in `text-pages.js`) |
| `contacts/` | `build-pages.js`: data sources page (text in `sources-text.js`, 5 languages) |
| `europe/`, `europe/<country>/`, `europe/<country>/<city>/` | `build-europe.js`: data in `europe-data.js`, texts in `text-europe.js`; English at the root |
| `luna/`, `luna/<year>/`, `luna/<year>/<month>/` | `build-luna.js`: Moon calendar for this and next year; phases from `js/moon.js`, texts in `text-luna.js` |
| `nebeto/` | `build-nebeto.js`: meteor showers, eclipses, supermoons, northern lights; events in `sky-events.json` (kept by hand, with sources, texts in 5 languages), page texts in `text-nebeto.js` |
| `za-saita/`, `poveritelnost/` | `build-static.js`: About and Privacy (texts in `text-static.js`) |

Change the script or its data file and run it again; changes made directly in the generated HTML are overwritten.

Languages: Bulgarian, English, German, Italian, Spanish (switcher in the header, saved in the browser).

**How pages are translated.** The generated pages exist once per language, each at its own URL: Bulgarian at the root (`/luna/`),
the others under a prefix (`/en/luna/`, `/de/luna/`, `/it/luna/`, `/es/luna/`). `/europe/` is the other way round: English at the root, the rest
under `/bg/europe/`, `/de/europe/` and so on. Every page has `<link rel="alternate" hreflang>` for all five and `x-default`; the language
switcher opens the translation of the same page, and a visitor who chose another language is sent from the root URL to it
(`page()` in `build-pages.js`, `language-selector.js`). City names in `/europe/` stay as in `europe-data.js`; country names come from `Intl.DisplayNames`.
The hand-written pages (home, forecast, maps, holidays, storms) and `/contacts/` are still translated in the browser from dictionaries in their scripts.

**Country context.** `js/place-context.js` reads the place the visitor picked on the forecast page (`lastLocation`; Sofia on a first visit).
The home page cities block (`js/home-cities.js`) then lists the main cities of that country (`js/destinations.json`), and `/nebeto/` (`js/sky-local.js`,
`js/aurora-kp.js`) shows times in the time zone of the place, a country picker, and eclipse and northern lights texts for that latitude instead of the Bulgarian ones.
The generated HTML stays written for Bulgaria; the scripts only replace it for other countries.

**Adding or changing text:** every generator takes its text from a `text-*.js` file (or `sky-events.json`) that has the same keys in all five
languages; change all five together. A new language needs its code in `i18n.js` and a text block in each of those files.

## Scripts

All scripts are in `.github/scripts/` and are run from the repository root with Node 20.

| Script | What it does |
|--------|--------------|
| `node .github/scripts/build-pages.js` | Writes the city, hub and holiday pages (all languages) and the sources page |
| `node .github/scripts/build-static.js [--sitemap]` | Writes the About and Privacy pages (all languages) |
| `node .github/scripts/build-europe.js [--sitemap]` | Writes the Europe pages (all languages); `--sitemap` adds missing URLs to `sitemap.xml` |
| `node .github/scripts/build-luna.js [year] [--sitemap]` | Writes the Moon calendar pages (the year and the next one) |
| `node .github/scripts/build-nebeto.js [--sitemap]` | Writes `/nebeto/` from `sky-events.json`; add next year's events there every autumn (IMO calendar for meteors) |
| `node .github/scripts/test-moon.js` | Checks `js/moon.js` against USNO phase times (`moon-reference.json`) |
| `node .github/scripts/test-sun.js` | Checks `sun.js` (sunrise/sunset on the city pages) against Open-Meteo (`sun-reference.json`) |
| `node .github/scripts/build-climate.js` | Refreshes `climate.json` (monthly climate from the ERA5 archive); rarely needed |
| `node .github/scripts/build-destinations.js [GR,CZ]` | Refreshes `js/destinations.json`, the one-tap city buttons under the search |
| `node .github/scripts/check-site.js` | Checks for missing local files and JavaScript/JSON syntax errors |
| `node .github/scripts/indexnow.js` | Sends the pages in `sitemap.xml` to IndexNow search engines |

Static assets use a version in the URL (`theme.css?v=N`). When a stylesheet or script changes, raise its version in the page templates (`VERSION` in `build-pages.js`) and regenerate.

## GitHub Actions

- **Site check** (`check.yml`): runs `check-site.js` on every pull request and push to `main`.
- **Moon calendar** (`luna-yearly.yml`): on 1 December builds the next year's `/luna/` pages and opens a pull request (an issue if Actions may not open PRs). Pull requests opened by Actions do not start the Site check; run it by hand.
- **IndexNow** (`indexnow.yml`): after pushes to `main` that change HTML or the sitemap, waits for Pages to publish and notifies Bing and others. Do not delete the key file `fd0de53b5adf000adbdcd0dff74d4364.txt` in the root: it proves the site is ours.

## Data sources

No API keys are needed. All services below are free and called directly from the browser.

- [Open-Meteo](https://open-meteo.com/): forecast (default "best match" blend of ICON, ECMWF IFS, GFS and Météo-France), ensemble for reliability, ERA5 archive for climate, geocoding
- [NOAA SWPC](https://www.swpc.noaa.gov/): geomagnetic Kp index
- [OpenStreetMap Nominatim](https://nominatim.openstreetmap.org/): reverse geocoding and country lookup
- [Windy](https://www.windy.com/): embedded weather maps
- [Nager.Date](https://date.nager.at/): public holidays

## Offline mode

The site is an installable PWA (`manifest.webmanifest`). `sw.js` caches the main pages for offline use. Add new top-level pages to the `PAGES` list in `sw.js` if they should work offline, and bump `CACHE` when cached files change in a way visitors must pick up.

## Hosting

GitHub Pages serves the `main` branch from the repository root. The custom domain is set in `CNAME`.

- `404.html` is shown for missing pages.
- `cookie-consent.js` shows the cookie banner and loads Google Analytics only after the visitor accepts.
- `.htaccess` and PHP do not work on GitHub Pages, so redirects and server-side code are not used.

## Adding a page

1. Create it (or add it to the generator and run the script).
2. Add it to `sitemap.xml` (`build-europe.js --sitemap` does this for Europe pages).
3. Add it to `sw.js` if it should work offline.
4. Run `node .github/scripts/check-site.js`.
